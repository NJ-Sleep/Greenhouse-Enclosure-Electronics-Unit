# Greenhouse Enclosure & Electronics Unit
> This uses the Arduino IDE
## REQUIREMENTS
- Arduino IDE
- In Files/Preferences add the following URL to Additional Board Manager URLs:
    > https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
- Download **esp32 by Espressif Systems** in Tools/Board Manager 
- Download **Adafruit SSD1306** and **Adafruit GFX** in Tools/Manage Libraries
